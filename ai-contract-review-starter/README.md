# AI Contract Review Agent Starter 🚀

An autonomous legal auditing pipeline to extract clauses and detect risks in legal agreements using **Multimodal LLMs**, **Marker OCR**, and **Custom Risk Matrices**.

> **"Turning Legal Logic into Executable Assets."**

[**Read the 3,500-word Bible Tutorial →**](https://xbstack.com/ai/how-to-build-ai-contract-review-agent/)

---

## 🌟 Features

- **Multimodal Layout Reasoning**: Reconstructs complex legal PDFs into clean Markdown.
- **Hierarchical Clause Extraction**: Identifies nested obligations and liabilities.
- **Risk Score Audit**: Automated 0-100 scoring based on pre-defined legal 'grammar'.
- **Digital Sovereignty**: Optional local deployment via DeepSeek-VL.
- **Stateful Recovery**: Integrated with [LangGraph Checkpointing](https://xbstack.com/ai/langgraph-memory-checkpointing-production-agents/) for long-running audits.

---

## 🛠️ Quick Start

1. **Clone**: `git clone https://github.com/xbstack/ai-contract-review-starter`
2. **Install**: `pip install -r requirements.txt`
3. **Run**: `python main.py --file ./contracts/agreement_v1.pdf`
